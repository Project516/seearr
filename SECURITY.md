# Security Policy

## Reporting a vulnerability

Report security issues privately through GitHub's [Report a vulnerability](../../security/advisories/new) form. Do not open a public issue.

Include the Seearr version, how you run it (Docker or bare metal), the steps to reproduce, and the impact you expect. You will get a reply as soon as the report has been read.

## Supported versions

Only the latest release receives fixes.

If the issue also affects upstream [Seerr](https://github.com/seerr-team/seerr), please report it there too.
