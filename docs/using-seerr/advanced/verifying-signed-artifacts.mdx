# Verifying Signed Artifacts

Seearr container images are signed with [Sigstore Cosign](https://docs.sigstore.dev/quickstart/quickstart-cosign/) by the release workflow (`release.yml`) on every `v*` tag push. Each image also has a CycloneDX SBOM attestation.

Verification confirms that the image was built by the release workflow of this repository.

## Prerequisites

- [Cosign](https://docs.sigstore.dev/cosign/system_config/installation/)
- [Docker](https://docs.docker.com/get-docker/) or [Podman](https://podman.io/getting-started/installation) with [Skopeo](https://github.com/containers/skopeo/blob/main/install.md)

## Verify a release image

Images are published to `ghcr.io/project516/seearr`. Verify the image digest, not the tag.

Set `TAG` to the release you pulled, then get the digest:

```bash
TAG=vX.Y.Z
DIGEST=$(docker buildx imagetools inspect "ghcr.io/project516/seearr:$TAG" --format '{{json .Manifest.Digest}}' | tr -d '"')
```

Verify the signature:

```bash
cosign verify ghcr.io/project516/seearr@"$DIGEST" \
  --certificate-identity "https://github.com/Project516/seearr/.github/workflows/release.yml@refs/tags/$TAG" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com"
```

The identity must match the release that produced the image.

The `latest` tag is mutable. To verify it, find the version it points to on the [releases page](https://github.com/Project516/seearr/releases) and set `TAG` to it.

## Verify the SBOM attestation

```bash
cosign verify-attestation ghcr.io/project516/seearr@"$DIGEST" \
  --type cyclonedx \
  --certificate-identity "https://github.com/Project516/seearr/.github/workflows/release.yml@refs/tags/$TAG" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com"
```

To save the SBOM for inspection:

```bash
cosign verify-attestation ghcr.io/project516/seearr@"$DIGEST" \
  --type cyclonedx \
  --certificate-identity "https://github.com/Project516/seearr/.github/workflows/release.yml@refs/tags/$TAG" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com" | jq -r '.payload | @base64d' > sbom.json
```
