# Owner Account

The user account created during Seearr setup is the "Owner" account, which cannot be deleted or modified by other users. This account has full administrative access to all Seearr settings and features.

:::tip
The owner account is responsible for configuring Radarr/Sonarr connections, managing users, and setting up notifications.
:::
