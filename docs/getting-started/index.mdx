:::info
**Seearr** is a lightweight media request manager for **Radarr and Sonarr**. It discovers content via TMDb and sends requests to your *arr services — no media server required.

After running Seearr for the first time, configure it by visiting the web UI at `http://[address]:5055` and completing the setup steps.
:::
